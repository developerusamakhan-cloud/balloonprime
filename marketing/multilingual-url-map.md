# Testmatik: Portuguese (Brazil) and Polish URL map

Source: Ubersuggest keyword data, Brazil (locId 2076, pt) and Poland (locId 2616, pl). Checked 2026-11-04.
SD = SEO difficulty (0-100, lower is easier). DA = domain authority of the sites ranking now.

Turkish stays at the root (`testmatik.app/...`). Portuguese lives under `/pt/`, Polish under `/pl/`.
Each page is linked to its translations with `hreflang`.

## Change to the plan: build the CPS test early

"cps test" gets 33,100 (Turkey) + 22,200 (Brazil) + 22,200 (Poland) = 77,500 searches a month.
It becomes a tool in all three languages right after the first Portuguese launch, instead of in late November.
The click counter already exists inside the mouse test, so most of the code is in place.
