6. PIN RULES THAT WORK
- Size 1000 x 1500 (2:3). The designed pins already use this size.
- Title: up to 100 characters, start with the main keyword (for example "How Much Does a Website Cost?").
- Description: 2 to 3 sentences with keywords, no hashtag spam (2 or 3 at most).
- Alt text: describe the pin in one sentence.
- Link: always the exact article URL, never only the homepage.
