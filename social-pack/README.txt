HOW TO USE THIS PACK
1. Open vyntic-30-day-calendar.xlsx. The "Calendar" tab has one row per upload: date, platform,
   time (US Eastern and Pakistan), files, caption, link and tips.
2. Open the day's folder inside Media. Upload the files listed for that platform.
3. Copy the caption from captions.txt in the same folder (or from the Calendar tab) and paste it.
4. After posting, set Status to Posted in the Calendar tab and paste the post link.
5. Save time: schedule the whole week on Sunday. Meta Business Suite (Instagram + Facebook),
   LinkedIn's scheduler, YouTube Studio and Pinterest's scheduler are all free.

- Watch reel-voiceover.mp4 once with sound.

  vyntic.studio. Only replace them with client results if the results are real.
