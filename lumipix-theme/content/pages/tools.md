Here are all our free image tools in one place, grouped by what you need to do.

## How to choose the right tool

Start with what the result needs to be. If a website or form gives you a **file size limit** such as 50KB or 200KB, use one of the compress tools. If it gives you **dimensions** in pixels, centimetres or inches, use the resizer. If you need a **transparent or plain background**, use one of the background tools.

Some tasks need two steps. A passport photo for an online form, for example, usually has both a size in millimetres and a maximum file size. Make it with the [passport photo maker](tool:passport-size-photo) first, then bring the downloaded file to the [compressor](tool:compress-image) and pick the limit from the form.

## What every tool has in common

- **Private:** images are processed in your browser and never uploaded.
- **Free:** no account, no watermark, no paid "HD" download.
- **Fast:** results appear in seconds, even on a slow connection.
- **Batch friendly:** the compressor and resizer accept up to 20 images at once.

## Frequently asked questions

### Which tool should I use for an online application form?

If the form states a size in KB, use the compressor and choose that limit. If it also states dimensions, resize first and then compress.

### Do I need to install anything?

No. All tools run in a modern web browser on a computer, tablet or phone.
