Print shops, publishers and some application forms want images "at 300 DPI". Checking only takes a few seconds, but the number itself is widely misunderstood. Here's how to check if a photo is 300 DPI, and what to do if it isn't.

## How to check DPI on Windows

1. Right-click the image file and choose **Properties**.
2. Open the **Details** tab.
3. Under **Image**, look for **Horizontal resolution** and **Vertical resolution**. They show the DPI, like 72 dpi or 300 dpi.

## How to check DPI on a Mac

1. Open the image in **Preview**.
2. Choose **Tools → Show Inspector**, or press Cmd+I.
3. The **General Info** tab shows **Image DPI**.

In Photoshop, it's shown as **Resolution** under **Image → Image Size**.

The quickest way on any device is the free [image resolution checker](tool:check-image-dpi). Drop a photo and it shows the stored DPI, the pixel size and how big it prints sharply at 300 DPI.

## What the DPI number really means

DPI is a **label** stored in the file. It tells printing software how big to print the image. It doesn't change the pixels. A 3000 x 2400 pixel image is:

- 10 x 8 inches at 300 DPI
- 41.7 x 33.3 inches at 72 DPI

Same image, same sharpness on screen, different print size. So the real question isn't "is it 300 DPI?" but "**does it have enough pixels for this print size at 300 DPI?**"

## Does my photo have enough pixels?

Multiply the print size in inches by 300:

- A 4 x 6 inch print needs 1200 x 1800 pixels
- An 8 x 10 inch print needs 2400 x 3000 pixels
- A4 needs 2480 x 3508 pixels

If your image has at least that many, it can print sharply at 300 DPI. Our [print size guide](post:image-size-in-inches-print-guide) has the full chart.

Phone photos often say 72 DPI in their properties even though they have millions of pixels. That's just a default label. The photo may still be perfect for printing.

## How to set a photo to 300 DPI

If it already has enough pixels and only the label is wrong, [change image DPI](tool:change-image-dpi) to 300. For JPG and PNG, only the DPI value changes, so the pixels and quality stay exactly the same.

If you want it at an exact print size:

1. Open the page to [resize image into inches](tool:resize-image-in-cm) or centimetres.
2. Set the unit to **inch**, **cm** or **mm**, and the DPI to **300**.
3. Type the print size you want.
4. Save as **JPG** and download. The 300 DPI value is saved in the file, so its properties will show it.

If the image has fewer pixels than the print needs, the resizer enlarges it. That fixes the label, but it can't add real detail, so very small images may still look soft on paper.

For passport and ID photos, the [passport size photo creator](tool:passport-size-photo) sets 300 DPI automatically.

## Why do some forms ask for 300 DPI?

Organisations that print your photo onto cards and certificates want enough detail for a clear print. Forms that only show photos on screen usually care more about pixel dimensions and file size. If a form wants 300 DPI and a small file size, make it the right physical size first, then [compress it to the limit](tool:compress-image).

## Checking on a phone

Phones don't show DPI in the gallery, because it doesn't matter on screen. To see the useful numbers:

- **Android.** Open the photo in Google Photos and tap the menu, or swipe up for **Details**. You'll see the resolution in megapixels and pixels, which is what actually matters for printing.
- **iPhone.** In Photos, swipe up on a photo to see its pixel dimensions.

Then use the formula: **pixels divided by 300 = the biggest size in inches at 300 DPI**. A 4032 x 3024 photo gives you 13.4 x 10 inches.

## A quick DPI calculator

You can work out the real DPI of any print by dividing pixels by inches:

| Image width | Printed width | Effective DPI | Result |
|---|---|---|---|
| 3000 px | 10 in | 300 | Sharp |
| 3000 px | 15 in | 200 | Good at arm's length |
| 3000 px | 20 in | 150 | Fine for a poster |
| 1200 px | 10 in | 120 | Visibly soft up close |

If the effective DPI drops below about 150 for something you hold in your hand, pick a smaller print or a bigger original.

## When a print shop rejects your file

Some shops reject anything "under 300 DPI" automatically, even when there are plenty of pixels. If your image has enough for the size, just set the DPI value with the Change DPI tool and download again. The file now says 300 DPI and the right print size. Nothing about the quality has been faked. You've simply told the printer how big to print it.

## DPI and file size

People often think a 300 DPI file is "bigger" than a 72 DPI one. The DPI value changes nothing about file size. Only the number of pixels and the compression do. So you can meet a small KB limit and still say 300 DPI. Make the photo at the right physical size, then compress it with the image compressor, which keeps the 300 DPI value of a JPG.

## Scanning at 300 DPI

When you scan documents or prints, use 300 DPI for normal use, or 600 DPI if you'll want to enlarge the scan later or capture very fine text. Higher settings mostly just make bigger files with no visible benefit for everyday documents. To get scans under a size limit, see [how to lower image file size](post:how-to-lower-image-file-size), and for the background on all this, read [what is DPI](post:what-is-dpi).

## The short version

- **Windows:** Properties → Details shows the resolution in DPI.
- **Mac:** Preview → Tools → Show Inspector shows the image DPI.
- **DPI is a label.** What matters is having enough pixels for the print size.
- **Set 300 DPI** by changing the value, or by resizing in inches or centimetres and saving as JPG.
- **Compression doesn't change DPI** when you use a tool that keeps it.

## Frequently asked questions

### How do I know if my photo is 300 DPI?

On Windows, check Properties, Details, Resolution. On Mac, open Preview, then Tools, Show Inspector, and look for Image DPI.

### Is 72 DPI bad for printing?

Not necessarily. 72 DPI is just a label. What matters is whether the image has enough pixels for the print size at 300 DPI.

### Can I change 72 DPI to 300 DPI without losing quality?

Yes, if you only change the label and keep the pixels. The image just prints smaller. Adding pixels to print bigger can't add real detail.

### How do I check DPI on my phone?

Phones show pixel dimensions rather than DPI. Divide the width in pixels by 300 to find the biggest sharp print width in inches.

### Does 300 DPI make the file bigger?

No. DPI is only a label. File size depends on the number of pixels and the compression.
