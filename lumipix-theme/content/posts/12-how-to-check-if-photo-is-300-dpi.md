Print shops, publishers and some application forms ask for images "at 300 DPI". Checking takes seconds, but the number is often misunderstood. Here is how to check if a photo is 300 DPI and what to do if it is not.

## How to check DPI on Windows

1. Right-click the image file and choose **Properties**.
2. Open the **Details** tab.
3. Under **Image**, look for **Horizontal resolution** and **Vertical resolution**. These show the DPI, for example 72 dpi or 300 dpi.

## How to check DPI on a Mac

1. Open the image in **Preview**.
2. Choose **Tools → Show Inspector** (or press Cmd+I).
3. The **General Info** tab shows **Image DPI**.

In Photoshop, the value is shown as **Resolution** in **Image → Image Size**.

## What the DPI number actually means

DPI is a **label** stored in the file that tells printing software how large to print it. It does not change the pixels. A 3000 × 2400 pixel image is:

- 10 × 8 inches at 300 DPI
- 41.7 × 33.3 inches at 72 DPI

Same image, same sharpness on screen, different print size. That is why the honest question is not "is it 300 DPI?" but "**does it have enough pixels for this print size at 300 DPI?**"

## Does my photo have enough pixels?

Multiply the print size in inches by 300:

- 4×6 inch print → needs 1200 × 1800 pixels
- 8×10 inch print → needs 2400 × 3000 pixels
- A4 → needs 2480 × 3508 pixels

If your image has at least that many pixels, it can print sharply at 300 DPI. Our [print size guide](post:image-size-in-inches-print-guide) has a full chart.

Phone photos often show 72 DPI in their properties even though they have millions of pixels. That is just the default label. The photo may still be perfect for printing.

## How to set a photo to 300 DPI

1. Open the [Image Resizer](tool:image-resizer).
2. Set the unit to **inch**, **cm** or **mm**, and DPI to **300**.
3. Enter the print size you want.
4. Under **Save as**, choose **JPG**, then download. The 300 DPI value is written into the JPG file, so its properties will show it.

If the image has fewer pixels than the print size needs, the resizer enlarges it. That fixes the label, but cannot add real detail, so very small images may still look soft when printed.

For passport and ID photos, the [passport photo maker](tool:passport-size-photo) sets 300 DPI automatically.

## Why do some forms ask for 300 DPI?

Organisations that print photos onto cards and certificates want enough detail for a clear print. Online-only forms usually care more about pixel dimensions and file size. If a form asks for both 300 DPI and a small file size, resize to the required physical size first, then [compress to the size limit](tool:compress-image).

## Checking DPI on a phone

Phones do not show DPI in the gallery, because it does not matter on screen. To see it:

- **Android:** open the photo in Google Photos, tap the **⋮** menu or swipe up for **Details**. You will see the resolution in megapixels and pixels, which is what actually matters for printing.
- **iPhone:** in Photos, swipe up on a photo to see its pixel dimensions.

Then use the formula: **pixels ÷ 300 = maximum inches at 300 DPI**. A 4032×3024 photo gives 13.4 × 10 inches.

## A quick DPI calculator

You can work out the effective DPI of any print by dividing pixels by inches:

| Image width | Printed width | Effective DPI | Result |
|---|---|---|---|
| 3000 px | 10 in | 300 | Sharp |
| 3000 px | 15 in | 200 | Good at arm's length |
| 3000 px | 20 in | 150 | Fine for a poster |
| 1200 px | 10 in | 120 | Visibly soft up close |

If the effective DPI is below about 150 for something held in the hand, choose a smaller print size or a higher-resolution original.

## When a print shop rejects your file

Shops sometimes reject files "under 300 DPI" automatically, even when the pixels are sufficient. If your image has enough pixels for the size, simply set the DPI value:

1. Open the [Image Resizer](tool:image-resizer).
2. Set the unit to **inch** or **cm**, DPI to **300**, and type the print size.
3. Choose **JPG** under **Save as** and download.

The file now reports 300 DPI and the correct print size. Nothing about the image quality has been made up; you have only told the printer how big to print it.

## DPI and file size

People often think a 300 DPI file is "bigger" than a 72 DPI file. The DPI value itself changes nothing about the file size; only the number of pixels and the compression do. That means you can meet a small KB limit and still state 300 DPI. Make the photo at the right physical size with the [passport photo maker](tool:passport-size-photo) or resizer, then compress it with the [Image Compressor](tool:compress-image). The compressor keeps the 300 DPI value.

## Scanning at 300 DPI

If you are scanning documents or prints, set the scanner to 300 DPI for normal use, or 600 DPI if you want to enlarge the scan later or capture very fine text. Higher settings mostly create larger files without visible benefit for everyday documents. For more on getting scans under a size limit, see [how to lower image file size](post:how-to-lower-image-file-size) and our explanation of [print sizes in inches and centimetres](post:image-size-in-inches-print-guide).

## Key takeaways

- **Windows:** Properties → Details shows the resolution in DPI.
- **Mac:** Preview → Tools → Show Inspector shows the image DPI.
- **DPI is a label**; what matters is having enough pixels for the print size.
- **Set 300 DPI** by resizing in inches or centimetres and saving as JPG.
- **Compression does not change DPI** when you use a tool that preserves it.

## Frequently asked questions

### How do I know if my photo is 300 DPI?

On Windows, check Properties → Details → Resolution. On Mac, open Preview → Tools → Show Inspector and look for Image DPI.

### Is 72 DPI bad for printing?

Not necessarily. 72 DPI is just a label. What matters is whether the image has enough pixels for the print size at 300 DPI.

### Can I change 72 DPI to 300 DPI without losing quality?

Yes, if you only change the label and keep the pixels. The image will simply print smaller. Adding pixels to print larger cannot add real detail.

### How do I check DPI on my phone?

Phones show pixel dimensions rather than DPI. Divide the width in pixels by 300 to find the largest sharp print width in inches.

### Does 300 DPI make the file bigger?

No. DPI is only a label. File size depends on the number of pixels and the compression.
