Websites, apps and forms often want an image at an exact size, like 600 x 400 pixels, 1080 x 1080 or 1920 x 1080. Typing two numbers sounds easy enough. But if your photo is a different shape, you can end up with something stretched or badly cropped. Here's how to resize a picture in pixels and get it right.

## Step 1: Find out the current size

Every digital image is a grid of pixels. A typical phone photo is about 4000 x 3000. To check yours:

- **Windows.** Right-click, then Properties, Details, Dimensions.
- **Mac.** Open it in Preview, then Tools, Show Inspector.
- **Lumi Pix.** Drop the image into the [image resizer](tool:image-resizer) and the size shows up in the list.

## Step 2: Understand aspect ratio

Aspect ratio is the shape of the image: width divided by height. 4000 x 3000 is 4:3. 1920 x 1080 is 16:9. 1080 x 1080 is 1:1.

If the target has the **same ratio** as your photo, you can resize straight away with no cropping. If it's **different**, something has to give. Either part of the image is cropped, empty space is added, or the image gets stretched.

## Step 3: Pick the right mode

**Keep proportions (link on).** Type just the width and the height is worked out for you. Use this when the exact height doesn't matter, like "make it 1200 pixels wide".

**Fill.** The image covers the exact size and whatever doesn't fit is trimmed from the centre. Best for thumbnails and profile pictures.

**Fit.** The whole image is kept and the leftover space is filled with a colour. Best when nothing can be cut off, like a product or a document.

**Stretch.** Forces the exact size and squashes the image. Rarely what you want, except for abstract backgrounds.

## Step by step in your browser

## Working out the height yourself

If you know the width you want and need to keep the shape, the formula is:

**new height = new width x (original height divided by original width)**

So a 4000 x 3000 photo resized to 1200 pixels wide becomes 1200 x (3000 / 4000) = 900 pixels tall. The resizer does this for you when the link is on, but it's nice to know where the number comes from.

## Fill or Fit? Some examples

| Original | Target | With Fill | With Fit |
|---|---|---|---|
| 4000 x 3000 landscape | 1080 x 1080 | Sides cropped, subject centred | Whole photo with bars top and bottom |
| 3000 x 4000 portrait | 1920 x 1080 | Top and bottom cropped | Whole photo with bars left and right |
| 1500 x 1500 square | 1080 x 1350 | Sides cropped a little | Whole photo with bars top and bottom |

Fill looks best when the subject is in the middle. Fit is safer for documents, products and group photos where nothing can be lost.

## Making an image bigger

Enlarging creates new pixels by blending the existing ones. A small step up looks fine, but doubling a small image makes it noticeably soft. If you need a big size, start with the biggest original you can find.

## Sizes for websites

Big images slow pages down. A good rule is to resize to the widest the image is ever shown, then double it for sharp screens:

| Where it appears | Display width | Upload width |
|---|---|---|
| Full-width banner | 1440 px | 1920 to 2400 px |
| Image in a blog post | 740 px | 1200 to 1480 px |
| Card thumbnail | 360 px | 720 px |
| Avatar | 64 px | 128 to 256 px |

After resizing, run them through the [image compressor](tool:compress-image) to around 100 to 300KB for large images. Pixels and file size are related but not the same thing. Our guide on [how to reduce image size in KB](post:how-to-reduce-image-size-in-kb) explains the link.

## Check the result

After you download, open the file and check:

- **Dimensions.** Right-click, Properties on Windows, or Cmd+I on a Mac.
- **Sharpness.** Zoom to 100% and look at edges and text.
- **The crop.** Make sure nothing important got cut off in Fill mode.

If it looks soft, it was probably enlarged. Start with a bigger original if you can.

## Frequently asked questions

### How do I resize an image to exact pixels without stretching?

Turn off the link, type the width and height, and choose Fill (to crop) or Fit (to add a background) instead of Stretch.

### How do I resize many pictures to the same size?

Drop up to 20 images into the resizer. The same width, height and fit mode are applied to all of them.

### What is the difference between pixels and DPI?

Pixels are the actual size of the image. DPI only tells a printer how many of those pixels to put in each inch of paper.

### How do I keep the aspect ratio when resizing?

Turn the link icon on and type only the width. The height is worked out from the original proportions.

### What size should images be for a website?

Resize to about twice the width they're shown at, then compress to 100 to 300KB for large images.
