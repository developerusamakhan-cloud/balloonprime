Photoshop is the classic tool for resizing images, and it does the job well. But if all you want is a photo at a particular size, opening a professional editor can feel like using a crane to lift a cup of tea. This guide covers both: how to resize an image in Photoshop properly, and a quicker free way to resize an image without Photoshop.

## Resizing in Photoshop, step by step

1. Open your image and choose **Image → Image Size** (the shortcut is **Alt+Ctrl+I** on Windows and **Option+Cmd+I** on Mac).
2. Make sure the **chain icon** between Width and Height is linked, so the proportions stay the same.
3. Choose the unit: **Pixels** for screens, **Centimeters** or **Inches** for print.
4. Type the new width. The height updates by itself.
5. For print, set **Resolution** to 300 pixels per inch.
6. Leave **Resample** ticked if you want to change the pixel count. Untick it if you only want to change the print size without touching the pixels.
7. Click **OK**, then **File → Export → Export As** or **Save a Copy** to save it.

### Which resample option?

Photoshop's **Automatic** setting is a sensible default. When making images smaller, **Bicubic Sharper** keeps edges crisp. When making them bigger, **Preserve Details 2.0** does the best job, although nothing can invent detail that was never captured.

### An exact size in a different shape

Say you need 1080 x 1350 from a landscape photo. Image Size will either squash the picture or refuse to match both numbers. Use the **Crop tool (C)** with a 4:5 ratio first, then resize. Or use **Image → Canvas Size** to add a border around the picture instead.

## Batch resizing in Photoshop with actions

If you do use Photoshop for lots of files, an action saves you repeating yourself:

1. Open one image, open the **Actions** panel and click **Create new action**.
2. Do the resize with **Image → Image Size** and save the file.
3. Stop recording.
4. Choose **File → Automate → Batch**, pick your action and the source folder, and run it.

The browser resizer does the same for up to 20 images without recording anything. Drop them in, set the size and click **Download all**.

## Keeping the quality

Whichever tool you use, these rules protect quality:

- **Resize from the original.** Every round of resizing and saving loses a little detail.
- **Make things smaller, not bigger.** Shrinking keeps an image sharp. Enlarging can only stretch the pixels that are already there.
- **Use the right format.** JPG for photos, PNG for graphics and text. Our [PNG vs JPG](post:png-vs-jpg) guide explains why.
- **Sharpen lightly after a big reduction.** Photoshop's **Unsharp Mask** at a low amount brings back crispness. Browser tools use high quality resampling automatically.

## Other free editors

Besides browser tools, there are free desktop options:

- **GIMP** (Windows, Mac, Linux). **Image → Scale Image** works a lot like Photoshop's Image Size.
- **Paint** (Windows). **Resize** by percentage or pixels, best for quick jobs.
- **Preview** (Mac). **Tools → Adjust Size**, with a handy list of common sizes.

They're good when you also need to draw or add notes. For pure resizing, a dedicated tool is simpler.

## When the file has to be small too

Resizing shrinks the file, but not always enough for strict limits. After resizing, run it through the [image compressor](tool:compress-image) to hit a target like 100KB. Our guide on [how to reduce image size in KB](post:how-to-reduce-image-size-in-kb) explains why resizing first and compressing second gives the best result.

## The short version

- **Image → Image Size** is the Photoshop command. Keep the chain linked to avoid squashing.
- **Crop first** when the new shape is different, then resize.
- **Shrink rather than enlarge** wherever you can. Enlarging can't add real detail.
- **For everyday jobs**, a browser resizer is faster and handles presets, print sizes and batches without a licence.
- **Resize first, compress second** when the file also has to meet a KB limit.

## Frequently asked questions

### How do I resize an image in Photoshop without losing quality?

Make images smaller rather than bigger where you can, keep the proportions linked, and use Bicubic Sharper when reducing. Save as a high quality JPG or PNG.

### How do I resize in Photoshop without stretching the image?

Keep the chain icon linked in Image Size. If you need a different shape, crop to the new ratio first or add canvas.

### Is there a free alternative to Photoshop for resizing?

Yes. Browser tools like the Lumi Pix image resizer work in pixels, centimetres or inches with DPI, for free, without uploading your photos.

### What is the shortcut for Image Size in Photoshop?

Alt+Ctrl+I on Windows and Option+Cmd+I on Mac.

### Can I resize images in Photoshop Express or on my phone?

Yes, mobile editors have basic resizing. For exact pixel or print sizes, a browser tool with units and DPI is often quicker.
