Use this tool to convert SVG to PNG at exactly the size you need, with a transparent background and sharp edges.

## From vector to a picture any app accepts

SVG files are vector graphics: shapes and paths described in code, so they stay crisp at any size. That makes SVG ideal for logos, icons and illustrations on websites. Outside the browser, though, many places expect an ordinary image. Social media profile pictures, document editors, presentation software, marketplaces and upload forms often ask for PNG or JPG. Converting to PNG gives you a fixed-size picture that works almost anywhere, while keeping transparency so the logo still sits cleanly on any background.

## How to convert SVG to PNG

1. **Drop your SVG files** onto the page or click to choose them. You can convert up to 20 at once.
2. **Convert to** is already set to **PNG**.
3. Choose a **Size**: 1×, 2× or 4× the SVG's own size, or type a custom width in pixels. The height follows the aspect ratio automatically.
4. Check the dimensions shown under each result.
5. Download the PNGs individually, or click **Download all** for one ZIP file.

PNG is lossless, so there is no quality slider. Every pixel is saved exactly as it was drawn.

## Choosing the right Size

A vector has no fixed resolution, so you decide how many pixels the PNG gets. Rendering larger gives more detail, and since the SVG is redrawn at the new size rather than stretched, the edges stay sharp.

| Size option | Result | Good for |
|---|---|---|
| 1× | Same size the SVG declares | Web use at the original size |
| 2× | Twice the width and height | High-density phone and laptop screens |
| 4× | Four times the width and height | Slides, documents and print drafts |
| Custom width | Exactly the width you type | Upload forms and platforms with a required size |

For example, an icon that declares itself as 200 × 100 becomes 400 × 200 at 2× and 800 × 400 at 4×. If a platform asks for a logo exactly 1000 pixels wide, type 1000 as the custom width and the height is calculated for you.

## SVG vs PNG

| | SVG | PNG |
|---|---|---|
| Type | Vector (shapes and paths) | Raster (pixels) |
| Scaling | Sharp at any size | Sharp up to its pixel size |
| Transparency | Yes | Yes |
| Editing | Change shapes and colours in a vector editor | Edit pixels in a photo editor |
| Accepted by | Browsers and design tools | Practically everything |

Keep the SVG as your master file and export PNGs from it whenever you need a new size. That way you never have to enlarge a small PNG, which always looks blurry.

## Fonts and linked images

This converter draws the SVG using your browser. If the SVG loads fonts or images from somewhere else, those files may not be available while rendering, and the text can appear in a fallback font instead. The fix is in the original design file: convert text to outlines or paths before exporting the SVG, and embed images rather than linking them. Then the SVG contains everything it needs and renders the same everywhere.

## Practical tips

- **Go bigger, not smaller.** When unsure, pick 2× or 4×. You can always reduce a large PNG later with the [Image Resizer](tool:image-resizer), but you cannot add detail to a small one.
- **Check the transparent background.** Place the PNG on a dark slide or page to make sure the logo looks right on both light and dark backgrounds.
- **Make a favicon.** For a site icon, the [Favicon generator](tool:favicon-generator) accepts SVG directly and builds every size you need.
- **Smaller files for websites.** If you are publishing the image online, you can convert the PNG to WebP with the [PNG to WebP converter](tool:png-to-webp).
- **Several logos at once.** Drop a whole set of icons, choose one **Size** and use **Download all**.

## Common problems and fixes

**The PNG looks blurry.** The 1× size is too small for where you are using it. Convert again at 2×, 4× or a larger custom width.

**The text is in the wrong font.** The SVG relies on an external font. Outline the text in your design app and export the SVG again.

**A picture inside the SVG is missing.** The SVG links to an external image. Embed the image in the SVG, then convert again.

**I need a white background, not transparency.** Switch **Convert to** to JPG and choose a **Background** colour. JPG has no transparency, so transparent areas are filled with that colour.

**The file will not open.** The browser could not decode the SVG, which can happen if the file is damaged or incomplete. Open it in a browser tab to check that it displays.

**The PNG is large in KB.** Very large custom widths create big files. Use the smallest size that still looks sharp where you need it, or compress the result with the [Image Compressor](tool:compress-image).

## Exporting a logo for different places

1. Start from the official SVG version of the logo.
2. Convert at 1× for a website header that already uses the logo at its natural size.
3. Convert at 4× for presentations and documents, where it may be shown large.

5. Keep all PNGs in one folder next to the SVG, named by size.

## When you only have a PNG

If you received a logo as a PNG on a white background and no SVG exists, this converter cannot help, because it needs a vector to redraw.
