## From vector to a picture any app accepts

SVG files are vector graphics. They're shapes and paths written in code, which is why they stay crisp at any size and why they're great for logos and icons on websites. Outside the browser, though, plenty of places want a normal image. Profile pictures, document editors, presentation software, marketplaces and forms often ask for PNG or JPG. A PNG gives you a fixed-size picture that works almost anywhere, and it keeps the transparency so your logo still sits cleanly on any background.

## Which size?

A vector has no fixed resolution, so you decide how many pixels the PNG gets. Because the SVG is redrawn at the new size rather than stretched, the edges stay sharp however big you go.

| Size | Result | Good for |
|---|---|---|
| 1x | The size the SVG declares | Web use at the original size |
| 2x | Twice the width and height | Sharp phone and laptop screens |
| 4x | Four times the width and height | Slides, documents and print drafts |
| Custom width | Exactly the width you type | Forms and platforms with a required size |

So an icon that declares itself as 200 x 100 becomes 400 x 200 at 2x and 800 x 400 at 4x. If a platform wants a logo exactly 1000 pixels wide, type 1000 and the height is worked out for you.

## SVG vs PNG

| | SVG | PNG |
|---|---|---|
| Type | Vector (shapes and paths) | Raster (pixels) |
| Scaling | Sharp at any size | Sharp up to its pixel size |
| Transparency | Yes | Yes |
| Editing | Shapes and colours in a vector editor | Pixels in a photo editor |
| Accepted by | Browsers and design tools | Pretty much everything |

Keep the SVG as your master file and export new PNGs from it whenever you need a different size. That way you never have to blow up a small PNG, which always looks blurry.

## Fonts and linked images

The converter draws the SVG using your browser. If the SVG pulls in fonts or images from somewhere else, they might not be there while it's drawing, and the text can show up in a fallback font. The fix is in the original design file: turn text into outlines or paths before exporting the SVG, and embed images instead of linking them. Then the SVG has everything it needs and looks the same everywhere.

## If something's not right

**The PNG looks blurry.** 1x is too small for where you're using it. Convert again at 2x, 4x or a bigger custom width.

**The text is in the wrong font.** The SVG relies on an external font. Outline the text in your design app and export again.

**A picture inside the SVG is missing.** The SVG links to an outside image. Embed it, then convert again.

**You want a white background, not transparency.** Switch **Convert to** to JPG and choose a background colour.

**The file won't open.** The browser couldn't read the SVG, which happens if the file is damaged or incomplete. Open it in a browser tab to check it displays.

**The PNG is big in KB.** Huge custom widths make big files. Use the smallest size that still looks sharp, or run it through the [image compressor](tool:compress-image).
