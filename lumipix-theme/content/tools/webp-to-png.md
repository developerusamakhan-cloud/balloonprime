## When you need a PNG instead

WebP is popular on websites because it makes images small, and it can store transparency. But lots of design apps, office programs and older editors still expect PNG when an image has a see-through background.

PNG has been the standard for graphics with transparency for years. Turn the WebP into a PNG and you've got a file that keeps clean edges and transparent areas in almost any program.

## PNG or JPG?

If the image has transparency, PNG is the one you want. Here's how the two compare for the same WebP:

| | Save as PNG | Save as JPG |
|---|---|---|
| Transparent background | Kept | Filled with a colour |
| Compression | Lossless, nothing new added | Lossy, set by the **Quality** slider |
| File size | Usually bigger | Usually smaller |
| Sharp text and flat colours | Stays crisp | Edges can go soft |
| Best for | Logos, icons, stickers, screenshots, graphics | Photos for sharing and printing |

If it's just a normal photo with no transparency, JPG is often the better pick. You can [convert WebP to JPG](tool:webp-to-jpg) on its own page. For the full comparison, see [PNG vs JPG](post:png-vs-jpg).

## Editing without losing more quality

Every time you save a JPG, it's compressed again and a little detail goes. PNG doesn't work like that. If you're going to crop, retouch, add text or combine the image with others, convert the WebP to PNG first and use that as your working copy. Save it as often as you like, then export a final JPG or WebP at the end if you need a smaller file.

One thing to know: converting can't fix the WebP. If the original already has blocky or blurry bits, the PNG keeps them exactly as they are. PNG stops any further loss, but it can't bring back detail that's already gone.

## If something looks wrong

**The PNG is much bigger than the WebP.** That's expected. PNG is lossless, so it can't squeeze photos as tightly as WebP. For a photo without transparency, convert to JPG instead.

**The background isn't transparent.** The original WebP didn't have transparency, and converting can't create it. To cut out a subject, [remove background for free online](tool:background-remover) with the AI tool, or [remove white background from image](tool:remove-white-background) files that sit on a plain white backdrop.

**An animation turned into a still.** Only the first frame of an animated WebP is converted, because a PNG holds one picture.

**Colours shifted a little.** Colours are converted to sRGB, the standard for screens and the web. You'll rarely notice.

**An iPhone photo won't open.** Most browsers can't read HEIC. Export it as JPG from the phone first.
