This free image resizer works in pixels, percent, centimetres or inches, for one photo or a whole batch.

## One resizer for screens and paper

Different jobs measure images differently. Websites and apps want pixels. Printers and many official forms want centimetres, millimetres or inches. Social networks want specific shapes. The Lumi Pix Image Resizer handles all of them with one set of controls, and it runs in your browser, so your photos never leave your device.

## How to resize

1. **Drop your images**, click **Choose files**, or paste with Ctrl+V. Up to 20 at once.
2. **Pick a preset** or type a width and height.
3. **Choose the unit**: px, %, cm, mm or inch. For physical units, set the DPI.
4. **Choose how the image fits** the new size (see below).
5. **Pick a format** under **Save as**, then download.

The hint under the controls always shows the resulting size in pixels, so you know exactly what you will get.

## Keep proportions or set an exact size

The **link** icon between width and height controls the aspect ratio:

- **Link on:** type the width and the height is calculated from the original proportions. Each image in a batch keeps its own shape. Ideal for "make it 1200 pixels wide".
- **Link off:** type both numbers to get an exact size. Then choose a fit mode.

## Fit, Fill and Stretch

| Mode | What happens | Best for |
|---|---|---|
| **Fit – add background** | The whole image is kept; empty space is filled with a colour you choose | Products, documents, group photos |
| **Fill – crop edges** | The image fills the frame; edges are trimmed from the centre | Thumbnails, wallpapers, profile pictures |
| **Stretch** | The image is forced to the exact size | Rarely; it distorts the picture |

## Print sizes with DPI

When you choose **cm**, **mm** or **inch**, set the DPI, normally 300 for photos. The resizer calculates the pixels for you: a 10×15 cm print at 300 DPI becomes 1181×1772 pixels. When you save as **JPG**, the DPI is written into the file, so print software and photo labs print it at the right physical size.

| Print size | Pixels at 300 DPI |
|---|---|
| 35 × 45 mm (passport) | 413 × 531 |
| 4 × 6 in | 1200 × 1800 |
| 10 × 15 cm | 1181 × 1772 |
| A4 | 2480 × 3508 |

For the full chart and tips on aspect ratios, read our [print size guide](post:image-size-in-inches-print-guide).

## Batch resizing

Drop up to 20 images and they are all resized with the same settings. With the link on, each keeps its own shape at the width you choose. With the link off and **Fit**, every image becomes exactly the same size with padding, which is perfect for product grids. Click **Download all** to save every file. Each file name includes its new size, such as `photo-1200x800.jpg`, so originals and copies never get mixed up.

## Changing format while resizing

Under **Save as**, choose **Same as original**, **JPG**, **PNG** or **WebP**. Use JPG for photos, PNG for graphics and transparency, and WebP for websites. When saving a transparent image as JPG, the transparent areas are filled with the background colour you pick. Our [PNG vs JPG guide](post:png-vs-jpg) explains which format suits which job.

## Resizing and file size

Making an image smaller in pixels usually makes the file much smaller too. If you also need a specific file size, such as under 100KB for a form, resize here first and then use the [Image Compressor](tool:compress-image). For the reasoning behind that order, see [how to lower image file size](post:how-to-lower-image-file-size).

## Quality matters

The resizer uses high-quality, multi-step resampling, so reduced images stay sharp without jagged edges. Enlarging cannot add detail that was never captured, so very small originals may look soft when made much larger; start from the largest original you have.

## Percentage resizing

Choose **%** as the unit to scale images by a percentage. 50% halves the width and height, which reduces the pixel count to a quarter and the file size by roughly the same amount. This is the quickest way to shrink a batch of large photos for sharing.

## Converting units

When you switch units, the resizer converts the current numbers so the size stays the same. For example, 1181 × 1772 pixels at 300 DPI becomes 10 × 15 cm. This makes it easy to check what a pixel size means on paper, or what a paper size means in pixels.

## Typical mistakes and how to avoid them

- **Stretching faces:** use Fill or Fit instead of Stretch.
- **Blurry prints:** make sure the pixel size is enough for the print at 300 DPI.
- **Huge files after resizing up:** enlarging adds pixels; only enlarge when needed.
- **Transparent areas turning white:** choose PNG or WebP under Save as to keep transparency.
