This free image resizer lets you resize an image by size in pixels, percent, centimetres or inches, for one photo or a whole batch, and your files never leave your device.

## One resizer for screens and paper

Different jobs measure images in different ways. Websites and apps think in pixels. Printers and plenty of official forms think in centimetres, millimetres or inches. Social networks want particular shapes. This resizer handles all of them with the same few controls.

## How to resize an image

1. **Add your images.** Drop them in, tap **Choose files**, or paste with Ctrl+V. Up to 20 at once.
2. **Pick a preset** or type a width and height.
3. **Choose the unit:** px, %, cm, mm or inch. For paper sizes, set the DPI too.
4. **Choose how the image fits** the new size (more on that below).
5. **Pick a format** under **Save as** and download.

The line under the controls always shows the final size in pixels, so there are no surprises.

## Keep the shape, or set an exact size

The **link** icon between width and height decides whether the proportions stay the same:

- **Link on.** Type the width and the height works itself out. In a batch, every image keeps its own shape. This is what you want for "make it 1200 pixels wide".
- **Link off.** Type both numbers to get an exact size, then choose a fit mode.

## Fit, Fill or Stretch?

| Mode | What it does | Good for |
|---|---|---|
| **Fit** | Keeps the whole image and fills the empty space with a colour you pick | Products, documents, group photos |
| **Fill** | Fills the frame and trims the edges from the centre | Thumbnails, wallpapers, profile pictures |
| **Stretch** | Forces the image to the exact size | Hardly ever, because it squashes the picture |

## Print sizes with DPI

Choose **cm**, **mm** or **inch** and set the DPI, usually 300 for photos. The resizer works out the pixels for you. A 10 x 15 cm print at 300 DPI becomes 1181 x 1772 pixels, for example. When you save as **JPG**, the DPI is written into the file, so print software and photo labs print it at the right size.

| Print size | Pixels at 300 DPI |
|---|---|
| 35 x 45 mm (passport) | 413 x 531 |
| 4 x 6 in | 1200 x 1800 |
| 10 x 15 cm | 1181 x 1772 |
| A4 | 2480 x 3508 |

## Doing a whole batch

Drop up to 20 images and they're all resized with the same settings. With the link on, each keeps its own shape at the width you chose. With the link off and **Fit**, every image ends up exactly the same size, which is great for a product grid. Tap **Download all** to save them. Each file name includes the new size, like `photo-1200x800.jpg`, so you'll never mix up copies and originals. For bigger jobs there's a page set up to [resize images in bulk](tool:resize-image-in-bulk).

## Changing the format at the same time

Under **Save as**, pick **Same as original**, **JPG**, **PNG** or **WebP**. Use JPG for photos, PNG for graphics and transparency, and WebP for websites. If you save a transparent image as JPG, the see-through areas get the background colour you chose. Not sure which to pick? Our [PNG vs JPG guide](post:png-vs-jpg) explains it.

## Size in pixels vs size in KB

Making an image smaller in pixels almost always makes the file smaller too. If a form also wants a file size, like under 100KB, resize here first and then use the [image compressor](tool:compress-image). There's a good explanation of why that order works in [how to lower image file size](post:how-to-lower-image-file-size).

## Will it stay sharp?

When you make an image smaller, the resizer uses high quality, multi-step resampling, so edges stay smooth and the result looks crisp. Making an image bigger is different. It can't invent detail that was never there, so a tiny original will look soft if you blow it up a lot. Always start from the biggest original you have.

## Resizing by percent

Choose **%** to scale by a percentage. 50% halves the width and the height, which leaves a quarter of the pixels and usually cuts the file size by about the same amount. It's the quickest way to shrink a pile of big photos before sharing them.

## Switching units

When you change the unit, the numbers are converted so the size stays the same. 1181 x 1772 pixels at 300 DPI becomes 10 x 15 cm, for example. Handy when you want to know what a pixel size means on paper, or the other way round.

## Mistakes worth avoiding

- **Stretched faces.** Use Fill or Fit instead of Stretch.
- **Blurry prints.** Check there are enough pixels for the print size at 300 DPI.
- **Huge files after making an image bigger.** Enlarging adds pixels, so only do it when you need to.
- **Transparent areas turning white.** Pick PNG or WebP under Save as.
