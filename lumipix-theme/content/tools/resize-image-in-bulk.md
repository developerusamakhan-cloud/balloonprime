## Batch resize without installing anything

Product shots for a shop, holiday photos for a gallery, screenshots for a report: they usually all need the same width or the same frame. This tool applies one set of options to the whole batch, so 20 images take about as long as one.

## How to resize images in bulk

1. **Drop your photos** onto the box, tap **Choose files**, or paste with Ctrl+V. Up to 20 at once.
2. **Set the size.** Type a width in pixels, tap a preset like Full HD or Instagram portrait, or switch the unit to percent, cm, mm or inches.
3. **Decide how shapes are handled.** Leave the link on to give every photo the same width while each keeps its own shape. Turn it off to give every photo exactly the same frame.
4. **Pick a format** if you need one, like JPG for smaller files or PNG to keep transparency.
5. **Download** each image, or tap **Download all (ZIP)** to save the whole batch in one file.

## Same width, or same frame?

There are two ways to bulk resize, and picking the right one saves you from stretched or cropped surprises.

- **Same width, own height** (link on). Every image becomes, say, 1200 pixels wide. A landscape photo ends up shorter than a portrait one, and nothing is cropped. Right for blog posts, galleries and documents.
- **Same frame** (link off). Every image becomes exactly, say, 1080 x 1080 pixels. Choose **Fill** to crop the edges so each photo fills the frame, or **Fit** to keep the whole photo with a background colour around it. Right for product grids and social media.

There's a stretch option too, but it squashes faces and objects, so it's best avoided for photos.

Resizing to a sensible width is also the easiest way to make files smaller. A 4000 pixel phone photo resized to 1600 pixels usually drops to a fraction of its original size.

## Resize by percent

Switch the unit to **%** to scale every image by the same amount, like 50% to halve each side. The photos keep their sizes relative to each other, which is handy when a batch mixes big camera pictures with small screenshots.

## Resize in cm or inches for printing

For a batch of prints, switch the unit to cm or inches and set the DPI, usually 300. Each JPG gets the right number of pixels and the DPI is saved in the file, so print software uses the size you picked. ## Tips for big batches

- Start from the original files. Images already shrunk by a chat app have lost detail that resizing can't bring back.
- Keep each batch to 20 images. For more, clear the list and run the next batch with the same settings.
- Check one result before you download the ZIP. The size under each file shows the final pixels and file size.
