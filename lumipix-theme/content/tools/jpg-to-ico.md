## What is inside the ICO file

An ICO file is a small container that holds the same icon at several sizes. Windows, browsers and apps pick the size that fits the place where the icon is shown.

| Size | Where it is used |
|---|---|
| 16 x 16 | Browser tabs, small lists in Windows |
| 32 x 32 | Taskbar, bookmarks, sharper tabs |
| 48 x 48 | Windows Explorer, desktop at normal scale |
| 64 x 64 | High resolution screens |
| 128 x 128 | Large icon views |
| 256 x 256 | Extra large icons in Windows |

Each size is stored as a PNG inside the ICO, so transparent backgrounds stay transparent.

## Square images work best

Icons are always square. If your JPG is wide or tall, the tool centres it on a transparent square without stretching it, which can leave empty space at the sides. For a tight, bold icon, crop your image to a square first with the [crop image tools](tool:crop-image) and the 1:1 ratio.

Simple images make the best icons. A full photo is hard to recognise at 16 pixels, while a single symbol, letter or face shot up close stays clear.

## Using the ICO file

**For a website,** upload the file to your site's root folder as favicon.ico. Browsers look for it there automatically.

**For a Windows folder,** right click the folder, open Properties, then Customize, click Change Icon and browse to your .ico file.

**For a desktop shortcut,** right click the shortcut, open Properties, click Change Icon and pick the .ico file.

## Getting a clean icon

- **Remove the background first** if your logo sits on white. [Remove white background from image](tool:remove-white-background) files so the icon has a transparent background.
- **Use the largest original you have.** The 256 pixel size needs enough detail to look sharp.
- **Avoid thin lines and small text,** which disappear at 16 pixels.

## Why ICO and not just PNG?

Modern browsers can use a PNG favicon, but many tools and crawlers still ask for /favicon.ico by name, and Windows needs ICO files for folder and shortcut icons. One ICO holding several sizes covers all of these at once, which is why the format is still around.
