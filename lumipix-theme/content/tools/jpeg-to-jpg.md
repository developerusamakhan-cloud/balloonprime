## Is JPEG the same as JPG?

Yes. JPEG and JPG are the same image format. The name comes from the Joint Photographic Experts Group, and early versions of Windows only allowed three letters in a file extension, so .jpeg became .jpg. Both still exist today.

So why convert at all? Because some upload forms, job portals and apps check the extension rather than the file itself, and turn away anything that does not end in .jpg. Converting gives you a file that passes that check.
