## How to pixelate an image

1. **Drop your photo** onto the page, click to pick it, or paste it with Ctrl+V. You can add up to 20 images at once.
2. **Move the Pixel size slider.** It goes from 2 to 64 pixels per block. Small blocks give a light mosaic, big blocks make the picture almost abstract.
3. **Pick the colours** if you like. All colours keeps the photo's own colours. Retro, Limited and Minimal reduce them for a game style look.
4. **Choose Save as.** PNG keeps the hard edges sharp. JPG makes a smaller file.
5. **Download** each image, or tap **Download all** for one ZIP.

Every change updates the result straight away, so you can try a few sizes before you save.

## Which pixel size should you use?

| Pixel size | Effect | Good for |
|---|---|---|
| 2 to 6 px | Soft mosaic, still easy to recognise | Subtle art effects |
| 8 to 16 px | Clear pixel look | Profile pictures, posters, thumbnails |
| 20 to 40 px | Strong blocks, shapes only | Backgrounds, teasers, hiding detail |
| 48 to 64 px | Almost abstract | Covering private content |

The right size depends on the image. A 4000 pixel wide photo needs bigger blocks than a small screenshot to get the same look.

## Pixelating to hide information

People often pixelate a photo before posting it to hide faces, number plates, addresses or names. A few things are worth knowing:

- **Use big blocks.** Small blocks over large text can sometimes still be read or guessed. The bigger the blocks, the safer.
- **This tool pixelates the whole image.** To hide one part, crop that area out with the [crop image tools](tool:crop-image) and pixelate it, or pixelate a copy and combine the two in a photo editor.
- **Check the result at full size** before you share it.

Because nothing is uploaded, you can safely pixelate private photos, documents and screenshots here.

## PNG or JPG?

PNG keeps every block crisp, with clean edges between the squares. That is usually what you want for a pixel look. JPG compresses the image and softens those edges a little, but the file is smaller. If the image has a transparent background, choose PNG to keep it. Our guide to [PNG vs JPG](post:png-vs-jpg) explains the difference in more detail.

## Tips

- **Resize first for a consistent look.** If you pixelate a set of photos for a website, give them the same width in the [image resizer](tool:image-resizer) first, then use the same pixel size for all of them.
- **Try Limited colours** for posters and graphic designs. Fewer colours make the blocks stand out.
- **Keep the original.** Pixelation removes detail for good, so always work on a copy.

## Questions people ask

**Can I undo pixelation on a downloaded file?** No. The colours inside each block are averaged, so the original detail is gone from that file. Keep your original if you might need it later.

**Does it work on a phone?** Yes. Open the page in any modern browser on Android or iPhone, choose a photo from your gallery and download the result.

## How the tool works

The image is shrunk so that each block becomes one pixel, which averages all the colours inside that block. If you choose fewer colours, each pixel is then rounded to the nearest step. Finally the small image is scaled back up with sharp edges, so every block becomes a solid square again. All of this runs in your browser using the canvas built into it.
