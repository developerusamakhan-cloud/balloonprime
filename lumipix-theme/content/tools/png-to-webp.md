This tool lets you convert PNG to WebP in your browser and get much smaller images for your website, with transparent backgrounds kept intact.

## Lighter images for the web

PNG is excellent for screenshots, logos and graphics, but PNG files can be heavy, especially when a photo or a detailed illustration has been saved as PNG. On a website, heavy images mean slower pages, more mobile data for visitors and bigger uploads to your content management system. WebP was designed with the web in mind. It supports transparency just like PNG, and with a quality setting it usually produces much smaller files. Current versions of the major browsers display WebP, so it is a practical replacement for PNG on most sites.

## Transparency stays transparent

WebP supports an alpha channel, so the transparent parts of your PNG remain transparent after conversion. Logos, icons, cut-out product photos and stickers can go straight onto a coloured header, a card or a dark-mode page without a white box around them. The **Background** colour option only matters when saving as JPG, so you can ignore it here.

## PNG vs WebP at a glance

| | PNG | WebP (from this tool) |
|---|---|---|
| Compression | Lossless | Lossy, set by **Quality** |
| Transparency | Yes | Yes |
| Typical file size | Larger | Usually much smaller |
| Best for | Master copies, editing, pixel-exact graphics | Publishing on websites |
| Opens in | Practically everything | Current browsers and many apps |

The key difference is in the first row. PNG keeps every pixel exactly. WebP saved here throws away detail you are unlikely to notice in exchange for a smaller file, and the **Quality** slider decides how much.

## Picking a Quality value

Different kinds of images react differently to compression. Photos hide small losses well. Screenshots, text and hard edges show them sooner. Use these as starting points, then check the result and the size line.

| Image type | Starting Quality |
|---|---|
| Photos that were saved as PNG | 75–85 |
| Product cut-outs with transparency | 85–92 |
| Screenshots with small text | 90–95 |
| Logos, icons and line art | 92–100 |

If you cannot see a difference between two settings, use the lower one. If text edges look fuzzy or flat colour areas show faint blotches, move the slider up and convert again.

## Size in pixels matters too

Converting keeps the same pixel dimensions. A 4000-pixel-wide PNG becomes a 4000-pixel-wide WebP, which is still far more than most page layouts need. For the biggest saving, resize the image to the width it is actually displayed at with the [Image Resizer](tool:image-resizer), then convert it here. ## Practical tips

- **Keep your PNG originals.** Edit and archive the PNG; publish the WebP. If you need to change something later, start again from the PNG.
- **Convert a whole folder of assets at once.** Drop up to 20 files, check a few results, then use **Download all**.
- **Name files clearly.** Keep the same file name with the new .webp extension so you can swap images on your site easily.
- **Check transparency on a dark background.** Place a converted logo on a dark page to confirm the edges look clean.
- **Clean the background first.** If a logo still has a white box, remove it with the [white background remover](tool:remove-white-background) and then convert the transparent PNG to WebP.

## Common problems and fixes

**The WebP is not much smaller.** Very small, simple graphics with few colours are already compact as PNG. Try a lower **Quality**, or keep the PNG for those files.

**Text or edges look soft.** Raise **Quality** and convert again from the original PNG.

**Colours look slightly different.** Colours are converted to sRGB, the standard colour space for the web. Most images look the same; files saved with an unusual colour profile may shift a little.

**An app will not open the WebP.** Some older desktop software and some upload forms still expect PNG or JPG. Keep the PNG for those, or use the [PNG to JPG converter](tool:png-to-jpg) when transparency is not needed.

**Only one frame was saved.** If you dropped an animated GIF or WebP, only the first frame is converted.

**Metadata has gone.** Re-encoding removes EXIF data such as camera model and GPS location, which also keeps files a little smaller.

## When to keep PNG instead

WebP is the better choice for publishing, but PNG still has its place. Keep PNG for files you will edit again, for graphics that must stay pixel-exact, and for any platform or form that only accepts PNG. For photos that do not need transparency, a JPG may also be acceptable; our [WebP vs JPG](post:webp-vs-jpg) comparison covers that choice in more detail.
