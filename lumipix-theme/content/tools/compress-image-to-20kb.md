Use this tool to compress image to 20KB online for photos and signatures on application forms, free and private.

## Why 20KB is a special case

Twenty kilobytes is one of the strictest limits you will meet. A typical phone photo is 2–5MB, so it has to shrink by one or two hundred times. Recruitment portals, admission forms and some government services use this limit for signatures and small photographs, because the images are displayed small and stored in large numbers.

At this size, simply lowering the quality does not work: the image turns into coloured blocks. The trick is to reduce the dimensions as well, so a decent quality fits into the budget. This page is set up for exactly that. The target is 20KB and the maximum width starts at 600 pixels, which suits signatures and portraits.

## How to compress to 20KB

1. **Crop first.** In your phone's gallery or any editor, crop a portrait to head and shoulders, or a signature tightly around the ink.
2. **Drop the image** onto this page or tap **Choose files**.
3. **Download** once the result shows **Fits target**.

You can process up to 20 files at once, for example a photo and a signature for several applications.

## Getting a clearer 20KB photo

- **Use a plain, light background.** It leaves more bytes for the face.
- **Light the face evenly.** Noise from dark photos uses up the budget quickly.
- **Avoid screenshots and forwarded copies.** Start from the original camera file.
- **Do not compress the same file twice.** Each round removes detail; go back to the original instead.

## Signatures at 20KB

Signatures compress very well because most of the image is white. For the cleanest result:

1. Sign with a bold black or dark blue pen on plain white paper.
2. Photograph it from directly above in daylight.
3. Crop tightly and increase brightness slightly so the paper looks white.
4. Compress here, or use the [signature resizer](tool:resize-signature), which also offers a 10KB option.

For a transparent signature to use on documents rather than forms, see [how to remove the white background from a signature](post:remove-white-background-from-signature).

## When the form has a minimum size too

Some forms ask for a file between, say, 10KB and 20KB. If your result comes out smaller than the minimum because the image is very simple, open **Advanced options** and raise the **Maximum width** (for example to 800), so more pixels are kept. If the form also gives exact pixel dimensions, resize to them first with the [Image Resizer](tool:image-resizer), then compress.

## Common reasons a 20KB upload is rejected

- **Wrong format.** The form wants JPG. This tool always saves JPG, so upload the downloaded file, not the original.
- **Just over the limit.** Some portals count 1KB as 1,000 bytes, others as 1,024. Lumi Pix aims under the stricter number.
- **Wrong dimensions.** The file size is fine but the pixel size is not. Resize to the stated dimensions first.
- **Picked the original by mistake.** On phones, choose the file from Downloads or Files, not the gallery.
